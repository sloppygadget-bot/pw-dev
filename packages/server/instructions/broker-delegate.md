# pw-dev broker delegate

This API is owned by the CDP broker and delivered through pw-dev. Use only
`{{SERVER_URL}}/_pwdev/broker/*`; do not call the broker port directly.

Fetch `{{SERVER_URL}}/_pwdev/delegates/broker/openapi.json` for advanced
instance, profile, network, and proxy-forward operations. Prefer the server
control-plane browser and session APIs for ordinary browser lifecycle work.
